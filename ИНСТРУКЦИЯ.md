# ZERNO: инструкция для команды и для сдачи на хакатон

ZERNO — платформа «умного» земледелия для фермеров Казахстана: поля на карте, миссии дрона, проверка фото посевов, аналитика NDVI, ИИ-помощник, PDF-отчёты и экстренная панель. Интерфейс на казахском, русском и английском.

---

## Часть 1. Как запустить у себя (для команды)

### Что установить один раз

| Программа | Версия | Где взять |
| --- | --- | --- |
| Node.js | 20.9 или новее | https://nodejs.org |
| Python | 3.12 | https://www.python.org (при установке отметить «Add to PATH») |
| PostgreSQL | 16 | https://www.postgresql.org/download/windows |

При установке PostgreSQL запомните пароль пользователя `postgres`.

### Шаг 1. Распаковать архив

Распакуйте `ZERNO_хакатон.zip` в папку **без пробелов в начале пути и не внутри другого архива**, например `C:\ZERNO`.

### Шаг 2. Создать базу данных

Откройте **SQL Shell (psql)** из меню Пуск, войдите под `postgres` и выполните:

```sql
CREATE ROLE zerno LOGIN PASSWORD 'zerno123';
CREATE DATABASE zerno OWNER zerno ENCODING 'UTF8' TEMPLATE template0;
```

### Шаг 3. Бэкенд (сервер)

Откройте PowerShell в папке проекта и выполните по очереди:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements-dev.txt
copy .env.example .env
```

Откройте `backend\.env` в блокноте и замените две строки:

```
DATABASE_URL=postgresql+psycopg://zerno:zerno123@localhost:5432/zerno
JWT_SECRET=любая-длинная-случайная-строка-не-короче-32-символов
```

Затем создайте таблицы и демо-ферму:

```powershell
.\.venv\Scripts\alembic upgrade head
.\.venv\Scripts\python -m app.seed
```

### Шаг 4. Фронтенд (сайт)

```powershell
cd ..\frontend
npm install
```

### Шаг 5. Запуск

Дважды щёлкните **`Запустить ZERNO.bat`** в корне проекта. Первый запуск собирает сайт (около минуты). Браузер откроется сам на http://localhost:3000.

- Нажмите **Explore Dashboard**, чтобы войти в демо-ферму без регистрации.
- Чтобы открыть с телефона, подключите его к тому же Wi-Fi и введите адрес, который bat-файл напечатает в окне (вида `http://192.168.x.x:3000`).
- Не закрывайте чёрные окна «ZERNO сервер» и «ZERNO сайт», пока работаете.

### Если что-то не работает

| Проблема | Что сделать |
| --- | --- |
| `python` или `npm` не найден | Переустановить с галочкой «Add to PATH», перезапустить PowerShell |
| Ошибка подключения к базе | Проверить пароль в `DATABASE_URL` и что служба PostgreSQL запущена |
| Сайт открылся, но данных нет | Повторить `.\.venv\Scripts\python -m app.seed` в папке `backend` |
| Хочется вернуть демо-данные | В приложении: **Настройки → Demo and system → Reset demo farm** |
| Телефон не открывает сайт | Разрешить Python и Node в брандмауэре Windows для частной сети |

Документация API после запуска: http://localhost:8000/docs

## Часть 2. Как сдать проект на хакатон

### Что подготовить

1. **Код.** Либо этот архив, либо ссылку на GitHub-репозиторий. Если GitHub — проверьте, что файлы `.env` туда **не попали** (они в `.gitignore`, но лучше убедиться).
2. **Описание проекта** (1 абзац). Можно взять готовое:
   > ZERNO — ИИ-платформа точного земледелия для фермеров Казахстана. Объединяет учёт полей, интерактивную карту, миссии дрона, проверку фото посевов, аналитику NDVI, ИИ-помощника, PDF-отчёты и экстренную панель на трёх языках. Рабочий MVP: все экраны работают с настоящим API и базой PostgreSQL.
3. **Демо-видео 2–3 минуты** по сценарию ниже (запись экрана: Win + G или OBS).
4. **Презентация** — проблема, решение, демо, что реально / что симуляция, дорожная карта (`ROADMAP.md`), команда.
5. **Список участников** с ролями.

### Сценарий демо (для видео и для защиты)

1. **Dashboard** — статистика фермы, предупреждения, активность.
2. **Карта полей** — клик по цветному маркеру показывает проблемную зону.
3. **Дрон** — построить маршрут, подтвердить контроль, запустить миссию и показать полёт. В конце приходит уведомление.
4. **AI Crop Doctor** — загрузить фото посева, прочитать отчёт, одобрить или отклонить.
5. **Аналитика** — тренд NDVI, карта, сравнение полей.
6. **AI-помощник** — спросить «Какое поле требует дополнительного осмотра?»
7. **Экстренная панель** — тревога, метка на карте, сирена.
8. **Отчёты** — создать и скачать PDF.
9. Переключить язык (иконка глобуса) — показать казахский.

### Что честно сказать жюри

Это MVP, часть источников данных пока симулирована. В интерфейсе и в PDF это подписано.

| Работает по-настоящему | Симуляция / демо |
| --- | --- |
| Аккаунты, фермы, поля, решения, отчёты, настройки (PostgreSQL) | Дрон — полёт моделируется программно |
| Формула NDVI | NDVI считается на сгенерированных снимках |
| Экстренная панель: запись тревоги, карта, сирена, ссылки звонка/SMS | Анализ фото — правила по цветам (OpenCV), не обученная модель |
| PDF-отчёты | Погода — примерные данные |
| | Помощник — шаблоны (или Claude, если задан `ANTHROPIC_API_KEY`) |

Экстренная панель **никогда сама не звонит в службы** — только открывает звонок/SMS на телефоне пользователя.
